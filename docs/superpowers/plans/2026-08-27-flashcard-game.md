# Flashcard Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third game type to the existing StudyWeb app: a flashcard
deck where a creator defines front/back card pairs, and a player flips
through a shuffled deck marking each card "จำได้" (known, removed) or
"ยังไม่จำ" (not yet known, sent to the back of the deck), looping until
every card has been marked known.

**Architecture:** Additive to the existing Next.js + Prisma app, following
the exact same pattern as the matching game and category sort game already
in this codebase. New `FlashcardSet`/`Flashcard` Prisma models alongside
the untouched `GameSet`/`Pair` and `SortSet`/`SortCategory`/`SortItem`. A
new pure logic module `lib/flashcard-game.ts`. Two new pages
(`/flashcard/edit/[id]`, `/flashcard/play/[id]`) and two new API route
files (`/api/flashcard-sets`, `/api/flashcard-sets/[id]`). The existing
home page (`app/page.tsx`) is modified to merge all three game types.

**Tech Stack:** Same as the existing app — Next.js 14 (App Router,
TypeScript), Prisma, SQLite (dev) / Turso (prod), Vitest, Vercel. No new
dependencies.

**Spec:** `docs/superpowers/specs/2026-08-27-flashcard-game-design.md`

## Global Constraints

- No authentication, no login, no access control — public app, single user.
- Prisma is the only DB access layer — no raw SQL.
- No in-memory server state (stateless API routes).
- Flashcard-game logic lives in its own pure module (`lib/flashcard-game.ts`),
  isolated from `lib/matching-game.ts` and `lib/sort-game.ts` — no shared
  code between any of the three game types' logic.
- Card interaction is click-to-flip (visual only) plus two buttons
  ("จำได้ ✓" / "ยังไม่จำ ✗") — both MUST be real `<button>` elements, not
  `<div onClick>`, for keyboard accessibility (a prior game type in this
  project shipped a `<div onClick>` category box that was keyboard-
  unreachable and had to be fixed after the fact — do not repeat that
  mistake here).
- A card marked "ยังไม่จำ" moves to the back of the deck (same round),
  not removed and not immediately retried.
- Minimum 1 card per set, enforced on save (client validation before any
  API call, and server validation on `PUT`).
- The play page's win condition MUST require the set had at least 1 card
  to begin with, not just "the deck is currently empty" — a set fetched
  with zero cards must never show a win banner (a prior game type in this
  project shipped exactly this bug and had to be fixed after the fact —
  guard against it explicitly in this plan's Task 6).
- The home page merge (Task 7) MUST let each game type's list fail
  independently — one game type's API failing must not blank out the
  other two game types' tiles (a prior game type's home-page merge used
  `Promise.all` naively and coupled all game types' failure modes
  together; this plan's Task 7 uses per-fetch `.catch(() => [])` from the
  start to avoid repeating that mistake).
- Existing matching-game and sort-game routes, pages, data, and tests must
  not change behavior — this plan only adds files and modifies
  `app/page.tsx` (already a multi-game-type file) and `README.md`.
- Reuse the existing design system: `app/globals.css` tokens/classes
  (`.page`, `.page-header`, `.page-title`, `.btn`/`.btn-primary`/
  `.btn-outline`/`.btn-ghost`, `.badge`, `.text-input`, `.empty-state`,
  `.error-banner`) and the existing `lib/fetch-json.ts` helper — do not
  duplicate these.

```typescript
export type Card = { id: string; front: string; back: string };

export function shuffleCards(cards: Card[]): Card[] {
  const copy = [...cards];

  for (let i = copy.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [copy[i], copy[j]] = [copy[j], copy[i]];
  }

  return copy;
}

export function moveToBack<T>(deck: T[]): T[] {
  if (deck.length <= 1) return [...deck];
  const [first, ...rest] = deck;
  return [...rest, first];
}
```

```typescript
export async function GET() {
  const sets = await prisma.flashcardSet.findMany({
    orderBy: { createdAt: "desc" },
    include: { _count: { select: { cards: true } } },
  });
  return NextResponse.json(sets);

export async function POST(req: NextRequest) {
  const body = await req.json();
  const title = typeof body.title === "string" ? body.title.trim() : "";

  if (!title) {
    return NextResponse.json({ error: "title is required" }, { status: 400 });

  const set = await prisma.flashcardSet.create({ data: { title } });
  return NextResponse.json(set, { status: 201 });
}
```

### Task 4: API routes — read, update, delete a single flashcard-set

**Files:**
- Create: `app/api/flashcard-sets/[id]/route.ts`

**Interfaces:**
- Consumes: `prisma` from `lib/prisma.ts`.
- Produces:
  - `GET /api/flashcard-sets/:id` → `200 { id, title, createdAt, cards: { id, front, back }[] }`, or `404` if not found.
  - `PUT /api/flashcard-sets/:id` with body `{ title: string, cards: { front: string, back: string }[] }` → replaces title and ALL cards for that set, `200` with the updated set (same shape as GET), or `400` on invalid input (title blank; fewer than 1 card after filtering; any card with a blank front or back after trimming).
  - `DELETE /api/flashcard-sets/:id` → `204`, cascades to delete its cards.

- [ ] **Step 1: Implement the route**

`app/api/flashcard-sets/[id]/route.ts`:
```typescript
import { NextRequest, NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";

export async function GET(_req: NextRequest, { params }: { params: { id: string } }) {
  const set = await prisma.flashcardSet.findUnique({
    where: { id: params.id },
    include: { cards: true },
  });

  if (!set) {
    return NextResponse.json({ error: "not found" }, { status: 404 });
  }

  return NextResponse.json(set);
}

export async function PUT(req: NextRequest, { params }: { params: { id: string } }) {
  const body = await req.json();
  const title = typeof body.title === "string" ? body.title.trim() : "";
  const rawCards = Array.isArray(body.cards) ? body.cards : null;

  if (!title || !rawCards) {
    return NextResponse.json({ error: "title and cards are required" }, { status: 400 });
  }

  const cards: { front: string; back: string }[] = [];

  for (const c of rawCards) {
    const front = typeof c.front === "string" ? c.front.trim() : "";
    const back = typeof c.back === "string" ? c.back.trim() : "";

    if (!front || !back) {
      return NextResponse.json(
        { error: "each card needs a non-blank front and back" },
        { status: 400 }
      );
    }

    cards.push({ front, back });
  }

  if (cards.length === 0) {
    return NextResponse.json({ error: "at least 1 card is required" }, { status: 400 });
  }

  const updated = await prisma.$transaction(async (tx) => {
    await tx.flashcard.deleteMany({ where: { setId: params.id } });

    return tx.flashcardSet.update({
      where: { id: params.id },
      data: {
        title,
        cards: { create: cards },
      },
      include: { cards: true },
    });
  });

  return NextResponse.json(updated);
}

export async function DELETE(_req: NextRequest, { params }: { params: { id: string } }) {
  await prisma.flashcardSet.delete({ where: { id: params.id } });
  return new NextResponse(null, { status: 204 });
}
```

- [ ] **Step 2: Implement the page**

`app/flashcard/edit/[id]/page.tsx`:
```tsx
"use client";

import { useEffect, useState } from "react";
import { useRouter } from "next/navigation";
import { fetchJson } from "@/lib/fetch-json";
import styles from "./page.module.css";

type CardInput = { front: string; back: string };

export default function EditFlashcardSetPage({ params }: { params: { id: string } }) {
  const router = useRouter();
  const isNew = params.id === "new";
  const [title, setTitle] = useState("");
  const [cards, setCards] = useState<CardInput[]>([{ front: "", back: "" }]);
  const [loading, setLoading] = useState(!isNew);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    if (isNew) return;
    fetchJson<{ title: string; cards: { front: string; back: string }[] }>(
      `/api/flashcard-sets/${params.id}`
    )
      .then((data) => {
        setTitle(data.title);
        setCards(data.cards.map((c) => ({ front: c.front, back: c.back })));
        setLoading(false);
      })
      .catch((err) => {
        setError(err.message);
        setLoading(false);
      });
  }, [isNew, params.id]);

  function updateCard(index: number, field: keyof CardInput, value: string) {
    setCards((prev) => prev.map((c, i) => (i === index ? { ...c, [field]: value } : c)));
  }

  function addCard() {
    setCards((prev) => [...prev, { front: "", back: "" }]);
  }

  function removeCard(index: number) {
    setCards((prev) => prev.filter((_, i) => i !== index));
  }

  async function save() {
    const cleanCards = cards
      .map((c) => ({ front: c.front.trim(), back: c.back.trim() }))
      .filter((c) => c.front && c.back);

    if (!title.trim() || cleanCards.length === 0) {
      alert("ต้องมีชื่อชุดโจทย์และการ์ดอย่างน้อย 1 ใบ");
      return;
    }

    try {
      if (isNew) {
        const created = await fetchJson<{ id: string }>("/api/flashcard-sets", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ title: title.trim() }),
        });

        await fetchJson(`/api/flashcard-sets/${created.id}`, {
          method: "PUT",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ title: title.trim(), cards: cleanCards }),
        });
      } else {
        await fetchJson(`/api/flashcard-sets/${params.id}`, {
          method: "PUT",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ title: title.trim(), cards: cleanCards }),
        });
      }
    } catch (err) {
      alert(err instanceof Error ? err.message : "บันทึกไม่สำเร็จ");
      return;
    }

    router.push("/");
  }

  if (error) return <p className="error-banner">{error}</p>;
  if (loading) return <p>กำลังโหลด...</p>;

  return (
    <main className="page">
      <div className="page-header">
        <h1 className="page-title">{isNew ? "สร้างชุดการ์ดใหม่" : "แก้ไขชุดการ์ด"}</h1>
      </div>
      <div className={styles.form}>
        <input
          className="text-input"
          value={title}
          onChange={(e) => setTitle(e.target.value)}
          placeholder="ชื่อชุดโจทย์"
        />
        <div className={styles.cardList}>
          {cards.map((card, i) => (
            <div key={i} className={styles.cardRow}>
              <div className={styles.cardHalf}>
                <input
                  className={styles.cardInput}
                  value={card.front}
                  onChange={(e) => updateCard(i, "front", e.target.value)}
                  placeholder="ด้านหน้า"
                />
              </div>
              <div className={styles.cardHalf}>
                <input
                  className={styles.cardInput}
                  value={card.back}
                  onChange={(e) => updateCard(i, "back", e.target.value)}
                  placeholder="ด้านหลัง"
                />
              </div>
              <button className={styles.removeBtn} onClick={() => removeCard(i)} aria-label="ลบการ์ดนี้">
                ✕
              </button>
            </div>
          ))}
        </div>
        <button className="btn btn-outline" onClick={addCard}>
          + เพิ่มการ์ด
        </button>
        <div className={styles.actions}>
          <button className="btn btn-ghost" onClick={() => router.push("/")}>
            ยกเลิก
          </button>
          <button className="btn btn-primary" onClick={save}>
            บันทึก
          </button>
        </div>
      </div>
    </main>
  );
}
```

`app/flashcard/play/[id]/page.tsx`:
```tsx
"use client";

import { useEffect, useState } from "react";
import Link from "next/link";
import { shuffleCards, moveToBack, type Card } from "@/lib/flashcard-game";
import { fetchJson } from "@/lib/fetch-json";
import styles from "./page.module.css";

export default function PlayFlashcardSetPage({ params }: { params: { id: string } }) {
  const [title, setTitle] = useState("");
  const [deck, setDeck] = useState<Card[] | null>(null);
  const [totalCards, setTotalCards] = useState(0);
  const [flipped, setFlipped] = useState(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    fetchJson<{ title: string; cards: Card[] }>(`/api/flashcard-sets/${params.id}`)
      .then((data) => {
        setTitle(data.title);
        setTotalCards(data.cards.length);
        setDeck(shuffleCards(data.cards));
      })
      .catch((err) => setError(err.message));
  }, [params.id]);

  function markKnown() {
    setDeck((prev) => (prev ? prev.slice(1) : prev));
    setFlipped(false);
  }

  function markUnknown() {
    setDeck((prev) => (prev ? moveToBack(prev) : prev));
    setFlipped(false);
  }

  if (error) return <p className="error-banner">{error}</p>;
  if (!deck) return <p>กำลังโหลด...</p>;

  const won = totalCards > 0 && deck.length === 0;
  const current = deck[0];

  return (
    <main className="page">
      <div className="page-header">
        <h1 className="page-title">{title}</h1>
        <Link href="/" className="btn btn-ghost btn-sm">
          ← กลับหน้าแรก
        </Link>
      </div>
      {won && <div className={styles.winBanner}>ยินดีด้วย! จำได้ครบทุกใบแล้ว 🎉</div>}
      {!won && current && (
        <>
          <p className={styles.progress}>เหลือ {deck.length} ใบ</p>
          <div className={styles.cardStage}>
            <button
              className={styles.card}
              data-flipped={flipped}
              onClick={() => setFlipped((f) => !f)}
            >
              {flipped ? current.back : current.front}
            </button>
          </div>
          <div className={styles.actions}>
            <button className={`btn ${styles.dontKnowBtn}`} onClick={markUnknown}>
              ยังไม่จำ ✗
            </button>
            <button className={`btn ${styles.knowBtn}`} onClick={markKnown}>
              จำได้ ✓
            </button>
          </div>
        </>
      )}
    </main>
  );
}
```

Note: `current` (i.e. `deck[0]`) is only `undefined` when `deck.length === 0`,
which is exactly the `won` condition — the `!won && current` guard means
the card stage and buttons never render without a current card, and the
`won` calculation's `totalCards > 0` guard prevents an empty-card set from
ever showing a win banner on load (see Global Constraints).
